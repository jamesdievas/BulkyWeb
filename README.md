# BulkyWeb
A .Net Application project
applying the basic MVC Architecture
- User
- Controller -> handles the user request and acts as an interface between the model and the View
- Model -> Represents the shape of the data
- View -> Represents the user interface

        User Clickes --> ( 1 - Request) --> COntroller --> (2- get Data) --> Model--> (Returns Data) --> Controller --> (3. send Data to be presented) --> View --> returns to --> Controller --> Response (Respondes to) --> User.
